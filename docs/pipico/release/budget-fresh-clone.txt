Reading the numbers:

- static RAM delta: exactly 20 B in every build (path-independent; .data
  and .bss hold no path strings). This matches the M3 canonical fresh
  evidence (20 B RAM).
- linked flash delta: 1200 B in the two local fresh clones (= the M3
  canonical 1200 B) and 1192 B on the CI runner. The small variance has
  the same cause as the non-reproducible hashes (reproducibility.md):
  error-diagnostic strings embed the absolute source path, so the
  string-constant sizes in .rodata scale with the build-path length
  (rb1/rb2 paths are the same length; the CI runner path is 28 bytes
  shorter). Every observed value is within roughly 0.02% of the 65536 B
  limit; the gate passed in every case.
